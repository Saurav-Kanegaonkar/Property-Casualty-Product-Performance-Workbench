# Data Dictionary

All tables are synthetic and generated by `scripts/score_operating_data.py`.

| Table | Grain | Purpose |
|---|---|---|
| `portfolio_monthly.csv` | month x underwriting segment | Monthly premium, loss, retention, claim, and ratio metrics for product performance monitoring. |
| `underwriting_segments.csv` | underwriting segment | State, product line, territory, exposure, inspection, telematics, automation, guideline, retention, and owner metadata. |
| `filing_backlog.csv` | state x product line | Rate indication, proposed change, filing complexity, readiness, manual sections, dependencies, and owner. |
| `workflow_requirements.csv` | business requirement | Product-to-IT requirements for reporting, review routing, filing tracking, and workflow improvement. |
| `analysis/outputs/product_action_queue.csv` | underwriting segment | Ranked product action queue based on combined ratio gap, rate indication, retention pressure, and exposure index. |
| `analysis/outputs/filing_readiness.csv` | state x product line | Ranked filing and product maintenance queue based on readiness score. |
| `analysis/outputs/automation_review_queue.csv` | underwriting segment | Ranked human review queue for automated underwriting decisions. |

## Core Measures

| Field | Meaning |
|---|---|
| `written_premium` | Modeled premium written in the month. |
| `earned_premium` | Modeled premium earned in the month. |
| `incurred_losses` | Modeled incurred losses. |
| `loss_ratio` | Incurred losses divided by earned premium. |
| `expense_ratio` | Synthetic expense load. |
| `combined_ratio` | Loss ratio plus expense ratio. |
| `retention` | Modeled policy retention rate. |
| `rate_indication` | Simplified product signal for potential rate need. |
| `proposed_rate_change` | Conservative modeled rate change for filing planning. |
| `readiness_score` | Filing readiness score, lower values need more preparation. |
| `review_score` | Human review priority for automated underwriting outcomes. |
| `action_score` | Product action priority for portfolio review. |
