# Data Sources

Synthetic source-style data for property and casualty insurance product performance analytics.

- `entities.csv`: 36 underwriting segment records.
- `daily_metrics.csv`: 5,040 underwriting segment-day metric rows.
- `source_events.csv`: 760 operational events, QA checks, experiments, and stakeholder asks.
- `recommended_actions.csv`: 220 candidate actions with effort and expected lift.
